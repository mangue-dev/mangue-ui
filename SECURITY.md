# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.x     | ✅        |

## Reporting a vulnerability

If you discover a security vulnerability in mangue-ui, please report it
responsibly:

1. **Do not open a public GitHub issue.**
2. Use [GitHub's private security advisory](https://github.com/mangue-dev/mangue-ui/security/advisories/new)
   to report it privately.

Include as much of the following as possible:

- The affected version(s)
- A description of the vulnerability and its impact
- Step-by-step instructions or a proof of concept to reproduce it

You can expect an initial response within 7 days. We will work with you on a
fix and coordinate a disclosure date before publishing anything.

Thank you for helping keep mangue-ui and its users safe.
